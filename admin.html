One-time setup

Connect Supabase to switch this on

The dashboard is built, but it has nowhere to save yet. These steps take about ten minutes and only need doing once.

  1. Create a free project at supabase.com/dashboard.
  2. Under Authentication → Users, add a user with your email and a strong password, and confirm it. Do this before the next step.
  3. Open SQL Editor, paste the contents of supabase/schema.sql and run it. That creates the tables, the security rules, the audio bucket, your 11 clips and the admin entry for that user.
  4. Under Project Settings → API Keys, copy the Project URL and the publishable key (older projects: anon public) into assets/data/supabase.js, then redeploy.

The publishable key is meant to be public — the security rules protect your data. Never put the service_role key in the repository: it bypasses every rule.
